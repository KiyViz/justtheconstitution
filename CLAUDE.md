# CLAUDE.md

**justtheconstitution.org** — static bilingual (EN/ES) site: the full U.S.
Constitution text plus National Archives parchment facsimiles. No framework —
plain HTML/CSS/JS assembled by a custom `build.js`.

## Two rules that prevent wasted work

1. **Edit source, not build output.** `index.html`, `en/`, `es/`, `404.html`,
   and every `*.min.*` are generated by `build.js`. The source of truth is
   `index.template.html`, `templates/`, `styles.css`, the root `*.js` modules,
   and `data/`. Editing a generated file is thrown away on the next build.
2. **Build with `node build.js`** — run `npm install` first. A missing
   `esbuild` makes the build silently ship unminified assets.

## Progressive context — read only what the task needs

Keep this file small. Pull in a detail file when the task calls for it:

| Read this file | When |
|---|---|
| `docs/architecture.md` | Build pipeline, full source-vs-generated map, JS module map, deploy. Any build or file-structure work. |
| `docs/conventions.md` | Breakpoints, theme/mode system, CSS variables, i18n string placeholders. Any CSS or UI work. |
| `docs/pr-log.md` | Chronological log of merged PRs. Project history / "why is X the way it is". |

## Workflow

- Branch from `origin/main` as `claude/<short-name>`. One source edit pulls in
  many regenerated outputs — commit them together.
- `docs/pr-log.md` is updated automatically when a PR merges, by the
  `Log merged PR` GitHub Action — no manual step needed.
